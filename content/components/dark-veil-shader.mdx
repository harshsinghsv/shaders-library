## Installation

**Option 1: Using CLI (Recommended)**

Install this shader directly using the CLI:

```bash
npx shaderz add
```

Select "Dark Veil" from the list. The component will be added to `/components/shaderz/Wavy.tsx`.

**Option 2: Manual Installation**

Copy the component code from the Usage section below.

## Required Dependencies

```bash
npm install three @types/three framer-motion
```

## Features

- **Smooth Gradients**: Beautiful blue-to-purple-to-magenta color transitions
- **Organic Motion**: Floating, noise-based movement creates a mysterious atmosphere
- **Soft Glow**: Radial gradient with subtle outer glow
- **Performance Optimized**: Efficient WebGL implementation
- **Dark Aesthetic**: Perfect for modern, elegant designs
