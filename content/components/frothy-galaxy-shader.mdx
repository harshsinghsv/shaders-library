## Installation

**Option 1: Using CLI (Recommended)**

Install this shader directly using the CLI:

```bash
npx shaderz add
```

Select "Frothy Galaxy" from the list. The component will be added to `/components/shaderz/FrothyGalaxyShader.tsx`.

**Option 2: Manual Installation**

Copy the component code from the Usage section below.

## Required Dependencies

```bash
npm install three @types/three framer-motion
```

## Features

- **Flowing Waves**: Smooth, organic wave patterns that create a fluid appearance
- **Blue Gradient**: Beautiful deep blue to light blue color transitions
- **Shimmer Effects**: Subtle sparkle and shimmer for added depth
- **Depth Fade**: Gradient fading creates a sense of depth
- **Performance Optimized**: Efficient WebGL implementation
- **Calming Aesthetic**: Perfect for peaceful, serene designs
