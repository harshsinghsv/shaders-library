## Installation

**Option 1: Using CLI (Recommended)**

Install this shader directly using the CLI:

```bash
npx shaderz add
```

Select "Liquid Motion" from the list. The component will be added to `/components/shaderz/LiquidMotionShader.tsx`.

**Option 2: Manual Installation**

Copy the component code from the Usage section below.

## Required Dependencies

```bash
npm install three @types/three
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `colors` | `string[]` | `['#5227FF', '#FF9FFC', '#B19EEF']` | Array of hex colors for the gradient |
| `shiny` | `boolean` | `true` | Enables specular highlights |
| `distort` | `number` | `0.3` | Amount of chromatic aberration |
| `className` | `string` | `''` | Additional CSS classes |
| `style` | `object` | `{}` | Inline styles |

## Features

- **Interactive**: Responds to mouse movement
- **Fluid Motion**: Smooth, organic flowing patterns using FBM noise
- **Customizable Colors**: Pass any array of colors for the gradient
- **Shiny Effects**: Optional specular highlights and chromatic aberration
- **Performance Optimized**: Efficient shader code with proper cleanup

## Customization

Customize the effect by modifying:

- **Color Palette**: Pass different colors via the `colors` prop
- **Shiny Mode**: Toggle `shiny` prop for specular highlights
- **Distortion**: Adjust `distort` for chromatic aberration intensity

## Technical Details

The shader uses:
- Fractal Brownian Motion (FBM) for organic flow patterns
- Mouse position tracking for interactivity
- Custom color palette sampling
- Three.js for WebGL rendering
