## Installation

**Option 1: Using CLI (Recommended)**

Install this video background directly using the CLI:

```bash
npx shaderz add
```

Select "Nova Silk" from the list. The video will be added to `/public/videos/nova-silk.mp4`.

**Option 2: Manual Installation**

1. Download the video file
2. Place it in your `/public/videos/` directory
3. Use it in your components as shown below

## Usage

**Basic Usage:**

```tsx
<video
  src="/videos/nova-silk.mp4"
  autoPlay
  loop
  muted
  playsInline
  className="w-full h-full object-cover"
/>
```

**Hero Section Background Example:**

