## Installation

**Option 1: Using CLI (Recommended)**

Install this shader directly using the CLI:

```bash
npx shaderz add
```

Select "Plasma V2" from the list. The component will be added to `/components/shaderz/Plasmav2Shader.tsx`.

**Option 2: Manual Installation**

Copy the component code from the Usage section below.

## Required Dependencies


## Features

- **Enhanced Color Mixing**: Improved purple-cyan gradient with better transitions
- **Fluid Motion**: Smooth, organic flowing patterns
- **Neon Glow Effects**: Vibrant neon palette with built-in vignette
- **Optimized Performance**: Efficient fragment shader for smooth animation

## Customization

Customize the plasma effect by modifying:

- **Wave Frequency**: Adjust the sine wave frequencies for different patterns
- **Color Palette**: Change the purple-cyan gradient to any color scheme
- **Glow Intensity**: Modify the vignette and glow strength
- **Animation Speed**: Control the plasma flow speed via the time multiplier

## Technical Details

The shader uses:
- Multiple nested sine/cosine wave layers for fluid distortion
- Gradient mixing between dark purple and cyan
- Radial vignette for depth and glow
- Time-based animation for continuous motion
- Optimized fragment shader for performance
